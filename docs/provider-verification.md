# 제공기관 명세 확인 기록

환경공단 공식 목록: https://www.data.go.kr/data/15076352/openapi.do

최신 공개 페이지는 가이드 v1.25, 요청 변수, 인증/요청 오류코드와 `statUpdDt`가 상태 변경시각이라는 점을 확인할 수 있습니다. 최신 가이드 본문의 상태·급속 유형 코드표 및 실제 인증 응답은 아직 확인하지 못했습니다. 따라서 사용자 제시 상태코드는 검토 대상이며 ME_STATUS_MAP, ME_FAST_TYPES, ME_MAPPING_VERIFIED를 임의 활성화하지 않습니다. 서비스키는 사용자가 요청한 `serviceKey` params 항목으로 전송하며 자동 디코딩하지 않습니다. 공개 페이지에는 `ServiceKey` 표기가 있으므로 대소문자 오류 응답 시 승인 가이드와 대조해야 합니다. 자동으로 이름을 바꾸어 키를 재전송하지 않습니다.

한전 공식 목록: https://www.data.go.kr/data/15147132/openapi.do

이 페이지는 LINK API이고 전력데이터개방포털의 Open-API 사용 매뉴얼.pptx를 안내합니다. 공개 페이지와 프로젝트 docs에서 공식 매뉴얼 본문을 확보하지 못했습니다. 이후 사용자가 제공한 승인 요청 예시에서 `apiKey`, `metroCd=11`, `cityCd=11`, `returnType=json`을 확인해 요청 계약에 적용했습니다. 이 근거를 공식 매뉴얼 전체 검증과 구분합니다. 예시에 없는 pagination은 미확인으로 기록하고 첫 응답만 검사합니다. 포털 접속의 원격 도구 오류를 사용자 Windows 로컬 API 실패로 판정하지 않습니다.

`kepco_request_contract.json`은 명시된 근거가 있는 요청만 기록합니다. 현재는 사용자 제공 예시를 근거로 요청만 활성화하며 공식 매뉴얼 확인 시 source를 보완합니다. 예시의 세 요청 변수를 그대로 전송하되, 필수 여부는 매뉴얼 미확인으로 기록합니다. 페이지가 없으면 공식 확인 후에만 pagination을 none으로 기록합니다. params에는 키를 넣지 않습니다. 키는 로컬 실행 시 루트 .env에서 주입합니다. items_path는 실제 응답 확인 후 채우며 첫 요청에는 필요하지 않습니다.

`scripts/test_kepco_api.py`는 요청 계약만 검증되면 응답 필드/상태 매핑이 없어도 1회 요청하고 구조만 출력합니다. 구조 증거는 data/runtime/kepco-schema.json에 저장하며 원문·키를 저장하지 않습니다. 이후 동일 설비 식별·시각·상태 의미까지 검증된 경우에만 운영용 KEPCO_CONTRACT/필드 매핑을 활성화합니다. 상태 의미가 불명확하면 상태 매핑은 비워둡니다. 한전 미검증은 환경공단/D1/D2 분석을 중단시키지 않습니다.
