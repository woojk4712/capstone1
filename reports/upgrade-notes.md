# 기능 확장 및 직접 검증 결과

2026-10-16. 좌측 내비게이션·상단 헤더/탭·흰색/회색 카드·지도 중심 배치를 재사용했습니다. 원본 XLSX는 변경하지 않았습니다.

## 변경한 동작

- 25개 자치구 선택: 지도 카메라 이동과 KPI·목록·복구 순위에 같은 시설 범위를 적용합니다. 데이터가 없는 구는 0개 시설(연결된 데이터의 빈 결과), 미연결은 `미연결`/`데이터 없음`으로 구분합니다.
- 시설 검색: 가나다순 스크롤 목록, 공백 정규화·포함/부분/오탈자 유사명 검색, 자치구 내 후보 우선, 키보드 화살표·Enter·Escape. 선택 시 이동·확대·마커 강조·상세 패널. 선택 시설과 충돌하는 상태·품질·출력 필터는 안내와 함께 초기화합니다.
- 지도: 실제 API `lat`/`lng`를 내부 `lat`/`lon`으로 보존하여 사용합니다. 핵심 시설과 주변 시설을 실선/점선 마커로 구분하고 정상·중지·점검·불확실을 색과 기호로 구분합니다. Hover Tooltip은 시설명만 표시하며 클릭 시 상세를 엽니다. 지도 영역의 휠은 Zoom, 드래그는 이동, 지도 밖은 페이지 Scroll입니다.
- 대체망: 선택 자치구 밖도 반경 안이면 포함합니다. 자기 시설은 제외하고 대체망은 분석대상 KPI나 수요 정규화 모집단에 합치지 않습니다. 기본 500m, 비교 1km입니다.
- KPI: 시설 수, 전체 설비 수, 정상/운영중지/점검/불확실 설비 수, 정상 정격출력과 출력미상 수를 현재 시설 필터에 맞게 갱신합니다. 설비 수는 출력 결측과 독립적으로 집계합니다. 상태 필터는 해당 상태가 있는 시설을 선택하며 KPI는 선택 시설의 전체 설비 기준이라고 표시합니다.
- 복구 우선순위: 해당 탭에서만 지도 옆 Ranking Panel을 표시합니다. 행 선택 시 기기를 강조하고 D/Q/B를 표시합니다. 운영중지의 적격 설비만 순위에 포함합니다.
- 새 산식: `Impact = (D + Q + B) / 3`, 범위 0~1, `impact-mean-v0.2`. D는 2025년 실제 급속 실적의 로그/Q95 정규화, Q는 시설 내 정격출력 비율, B는 `200/(200+A)`입니다. 기존 곱셈식은 legacy 회귀검사로만 보존하며 새 실행과 혼용하지 않습니다.
- 복구 시뮬레이션: 해당 탭에서만 체크·전후 비교를 표시합니다. 회복 kW·회복률(기준 중지 kW 대비)·정상/중지 설비 수·출력 감소·기준 상위 10기 미복구를 현재 필터 범위에 표시합니다. 전후 비교 모집단은 개선 전 선택조건으로 고정합니다. 다른 탭은 항상 실제 기준 스냅샷을 표시합니다.
- 정비 화면: 지도·복구 기능을 숨기고 해당 시설의 실제 세션 중첩 히트맵과 1/2시간 후보를 보여줍니다. 세션·커버리지·급속 전용 이력이 없으면 추천을 보류합니다. 샘플 시설에 실제 세션이 없으면 가짜 히트맵을 생성하지 않습니다.
- 품질 화면: 지도·복구 기능을 숨기고 실제 연결 상태·관측시각·출력미상·불확실 상태·2025년 원자료 출처를 표시합니다.
- 실행: `run-local.cmd`는 서버 상태를 확인하고 필요할 때 백그라운드로 시작한 뒤 기본 브라우저를 엽니다. 동일 포트를 여러 서버가 공유하지 않도록 새 서버에는 배타적 바인딩을 적용했습니다.

브라우저 검사 상세는 [ui-verification.json](ui-verification.json), 재실행은 `node scripts/ui-check.mjs`입니다. 이 환경의 내장 Playwright 또는 설치된 playwright와 Chrome이 필요합니다. 기존 사용자 Chrome 프로필은 사용하지 않았습니다. 아래 항목을 실제 클릭/입력/마우스 이벤트로 확인했습니다.

3. 자치구 변경 → 지도 중심·목록·KPI 변경 및 빈 자치구 처리
4. 검색 클릭 → 가나다순 목록과 스크롤
5. 부분·유사명 검색
6. 검색 선택 → 지도 확대·강조·상세

8. 지도 Wheel → Zoom 변경, 페이지 위치 고정
9. 지도 Drag 및 +/- 버튼
10. 지도 밖 Wheel → 페이지 Scroll
11. 운영현황에서 순위표·복구 체크·비교 UI 숨김
12. 우선순위 Panel → 지도·기기 상세·D/Q/B
13. 시뮬레이션 → 전후 출력·설비 수·가상 표시·타 탭 격리·초기화

17. 브라우저 런타임 오류 없음

## 검증 한계

- `.env`에 두 API 키가 확인되지 않아 실제 충전소 실인증·상태 코드 검증은 여전히 미완료입니다. 실제 모드에는 샘플이 자동 노출되지 않습니다. 실제 좌표 매핑은 제공기관 형태의 테스트 응답으로 검사했습니다.
- 타일 네트워크 연결은 환경 제약으로 확인하지 못했습니다. 브라우저 기능 검사에서는 외부 타일 요청을 차단하고 배경 안내 및 실제 지도 좌표 투영/조작을 검사했습니다. 깨진 이미지 아이콘은 숨깁니다.
- React/Vite 의존성 설치와 빌드, 주입형 MapLibre/ECharts 실행은 npm 네트워크 제한으로 미검증입니다. 직접 UI 검사는 표준 HTTP/공유 JS의 로컬 경량판에서 수행했습니다.
- 현행 자치구 경계 원문이 없어 경계선 강조는 보류했습니다. 구별 이동용 범위는 KOSTAT 2013 지도 좌표의 bbox만 참조하며 현행 행정구역 판정이나 충전소 좌표 대입에 사용하지 않습니다. 자세한 출처는 apps/web/src/MAP_SOURCES.md입니다.
