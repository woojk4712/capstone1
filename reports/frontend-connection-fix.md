# 프론트엔드 실데이터 연결 수정 결과

백엔드, `.env`, API 키, URL 및 FastAPI 수집 코드는 이번 작업에서 변경하지 않았습니다. 실행 중인 실제 서버의 내부 API만 브라우저에서 확인했습니다.

## 원인과 변경

주 화면의 기존 `Promise.all`은 `/api/chargers` 외에 분석용 `/api/v1/overview`의 완료까지 기다렸습니다. 분석 결과가 지연되거나 실패하면 충전기 데이터도 표시하지 않았습니다. 기존 지도 adapter 역시 분석 응답에 이미 들어 있는 충전소만 남겼습니다. 연결 상태를 `Boolean(state.base)`로 판단한 탓에 분석 데이터의 부재가 API 미연결처럼 보였습니다.

실데이터 모드의 최초 화면은 이제 same-origin `fetch('/api/system/status')`, `fetch('/api/chargers')`를 사용합니다. 분석용 overview가 최초 데이터 표시를 막지 않습니다. 기존 분석 API는 검증된 분류의 분석 탭에서 별도로 사용하며, 명시적 샘플 모드와 데이터 품질 보고서 경로는 유지합니다.

- API 연결은 `providers.ME.connected === true && providers.ME.current_error === null`로 판단합니다.
- 데이터 연결은 `/api/chargers` HTTP 200과 실제 반환 행 존재 여부로 판단합니다.
- `classification_verified=false`는 별도 분류 검증 안내로 표시합니다. 유형·상태코드 매핑을 추측하지 않았습니다.
- `statId`, `chgerId`, `statNm`, `addr`, `lat/lng`, `output`, `chgerType`, `stat`, `statUpdDt`를 프론트 변환 계층에서 사용합니다. 문자열 좌표를 숫자로 변환하고 잘못된 좌표는 지도에서 제외합니다. 좌표 없는 항목은 목록에서 확인할 수 있습니다.
- 같은 `statId`의 충전기를 충전소 하나로 묶습니다. Hover는 충전소명, Click은 실제 충전기 상세를 표시합니다. 상세에는 제공된 유형/상태 원본 코드와 상태 갱신시각도 표시합니다.
- Leaflet 1.9.4 JS/CSS와 라이선스를 검증된 npm 캐시에서 복구하여 프로젝트 내부 파일로 제공합니다. CDN 실패로 SVG 지도에 머무르던 문제를 제거했습니다. 많은 충전소는 Leaflet Canvas 마커로 그립니다.
- 목록은 처음 100개 충전소를 표시하며 검색/필터는 전체 데이터에 적용합니다. 가짜 데이터로 대체하거나 전체 데이터를 100개로 잘라 저장하지 않습니다.
- 브라우저의 localStorage/sessionStorage에 연결 상태를 저장하는 코드는 없었습니다. API 조회에는 `cache: 'no-store'`를 사용하고 실패 후 재조회 성공 시 화면 상태를 갱신합니다.

## 실제 브라우저 확인 결과

| 항목 | 결과 |
|---|---|
| `/api/system/status` 프론트 호출 | HTTP 200 |
| `/api/chargers` 프론트 호출 | HTTP 200 |
| SQLite 저장 충전기 수 | 76,163건 (status 응답) |
| 표시용 반환 충전기 수 | 75,506건 |
| 프론트 데이터 mapping | 실제 JSON 필드 및 문자열 좌표 변환 완료 |
| Leaflet 충전소 마커 | 12,936개 (`statId`로 그룹화) |
| 환경공단 표시 | 환경공단 연결됨 |
| 데이터 표시 | 실제 충전기 데이터 연결됨 |
| 분류 표시 | 충전기 유형 분류 기준 검증 필요 |
| 실제 Leaflet Hover/Click | 충전소명 Tooltip 및 일치하는 상세 패널 확인 |
| JavaScript 런타임 오류 | 0건 |
| Mock 자동 대체 | 사용하지 않음 |

저장 건수와 표시용 반환 건수는 별도로 표시합니다. 기존 백엔드의 미분류 표시 목록은 `delYn=Y` 항목을 제외하며, 백엔드 정책은 변경하지 않았습니다. 지도 마커 수는 충전기 행 수가 아닌 유효 좌표를 가진 충전소 수입니다.

검증 시 외부 지도 타일 요청만 차단했습니다. 실제 Leaflet 라이브러리와 실제 충전기 좌표를 사용했으며, 배경 타일 연결 성공을 주장하지 않습니다. API 요청은 실행 중인 동일 FastAPI 서버로만 보냈습니다.

추가 검증: 데이터 모델 테스트 11개 통과. 별도 격리 브라우저 테스트에서 문자열 좌표, 잘못된 좌표 제외, 분류/연결 상태 분리, Hover/Click/상세 필드, 오류 후 회복을 확인했습니다. 테스트 응답은 브라우저에만 주입했으며 운영 DB와 운영 데이터에는 저장하지 않았습니다.
